# Employee Management SQL Project

A beginner-friendly Employee Management System built using MySQL.

## About the Project

This project demonstrates basic SQL and database management concepts using an employee database.

## Technologies Used

- MySQL
- SQL

## SQL Concepts Covered

- Database and table creation
- INSERT
- SELECT
- WHERE
- ORDER BY
- UPDATE
- DELETE
- LIKE
- BETWEEN
- COUNT
- AVG
- MAX
- MIN
- GROUP BY
- DISTINCT

## Project Purpose

The purpose of this project is to practice SQL queries and understand how employee data can be stored, managed, filtered, and analyzed using a relational database.
